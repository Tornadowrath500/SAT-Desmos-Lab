# SAT-Desmos-Lab

An interactive study tool for the digital SAT math section. It teaches how to use the built-in Desmos calculator well, with lessons, generated practice problems, a trick library, and a Desmos-style lab calculator alongside the official SAT calculator.

Features
Learn: Five interactive lessons.
Regression from a table, with steps that check your work as you type.
Systems of lines, with sliders and a goal point.
Quadratics, linking roots, sum, product, and vertex.
Inequalities, with shading and a test point.
Circles, linking standard form and the radius trick.
Practice: Generated problems with guided solutions, covering:
Algebra: linear equations, systems, inequalities, rates, percent change.
Advanced Math: roots, vertex, line and parabola, exponential growth, function composition, exponent rules, exponential and quadratic regression.
Problem Solving & Data: mean, median, probability, linear regression.
Geometry & Trig: circle equation, circle area, Pythagorean theorem, sine ratio.
Calculator:
SAT calculator: The official Desmos testing calculator, embedded.
Lab calculator: A Desmos-style workspace with:
Function plotting, y = expressions
Inequality shading with y > and y <
Vertical lines, circles, and points
Automatic sliders for free variables
Tables with draggable points
Linear, quadratic, and exponential regression with R²
Tricks: Desmos moves grouped by type. Examples with a “Try” button load straight into the lab calculator.
